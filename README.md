
# Chef's Menu Manager

## MAST5112 – Portfolio of Evidence (Part 3)

Chef's Menu Manager is a React Native application developed to help manage a restaurant menu. The application allows users to add, view, edit, delete, search and filter menu items, as well as view useful menu statistics.

## Application Features

- Add new menu items with a dish name, description, course and price.
- View all saved menu items.
- Edit and update existing menu items.
- Delete menu items with a confirmation message.
- Search for menu items by dish name.
- Filter menu items by course:
  - Starter
  - Main Course
  - Dessert
- Clear search and course filters.
- View dashboard statistics, including:
  - Total number of menu items.
  - Average menu price.
  - Number of items in each course.
- Save menu items locally using AsyncStorage.
- Form validation and user feedback.
- Responsive interface with dashboard, menu management and insights sections.

## Installation and Running the Application

To run the application locally:

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal inside the project folder.
4. Install the project dependencies:

   ```bash
   npm install
   ```

5. Start the web version of the application:

   ```bash
   npm run web
   ```

6. The application should open in your web browser.
